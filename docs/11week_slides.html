왜 도메인 · HTTPS가 필요한가

구글 로그인은 돌아올 주소가 HTTPS여야 하고 IP 주소는 쓸 수 없음 → 무료 도메인 + Caddy로 해결

만든 서버
  • Ubuntu · 2 vCPU · 메모리 2GB
  • 디스크 20GB
  • SSH는 내 IP만 허용
  • 웹 포트(80 · 443)만 열기
    → 인증서 발급 후 내 IP로 제한 예정

메모리 2GB로 될까

로컬에서 측정해 보니 서버 + DB가 쉬는 상태에서 약 800MB. 처음 데이터 받을 때는 더 쓰므로 swap(가상 메모리) 2GB를 만들어 둠 → 실행하며 확인 예정

시세 데이터

재배포 금지 조건이라 프로젝트에 넣지 않고, 서버가 직접 받아서 채우도록 함

겪은 문제와 해결 데이터 · Docker · 화면

문제원인해결
ETF 포트폴리오 0종목초기화 SQL은 DB를 처음 만들 때 한 번만 실행월별 SQL 파일로 따로 적재
DB 도구에서 내보낸 SQL 실행 안 됨INSERT 문이 아닌 형식으로 내보내짐정상 INSERT 문으로 변환
화면을 고쳐도 Docker에 반영 안 됨컨테이너는 빌드할 때 소스를 복사해 둠화면 컨테이너 다시 빌드
PowerShell에서 DB에 SQL 넣기 실패PowerShell이 따옴표를 바꿔 버림파이프로 전달하는 방식으로 변경
구글 로그인 주소 오류로그인 주소 변경으로 돌아올 주소가 달라짐주소 설정 복구
로그인 후 화면이 그대로로그인 상태를 화면이 반영하지 않음로그인되면 첫 화면으로 자동 이동

겪은 문제와 해결 서버 · 배포

문제원인해결
구글 로그인에 서버 IP 사용 불가구글은 HTTPS 도메인 주소만 허용무료 도메인 + 자동 HTTPS(Caddy)
서울 리전 선택 불가새 계정이 시드니로 고정되어 표시됨시드니에서 진행
서버 접속(SSH) 시간 초과같은 장소에서도 내 IP가 바뀌어 규칙과 달라짐현재 IP 확인 후 규칙에 추가
서버에 올린 코드에 컨트롤러 누락.gitignore의 API/ 규칙이 윈도우 대소문자 무시로 api 패키지까지 막음최상위 폴더 전용 규칙으로 수정
리눅스 빌드에서 실행 파일 오류 위험윈도우 줄바꿈(CRLF)빌드할 때 줄바꿈 변환
