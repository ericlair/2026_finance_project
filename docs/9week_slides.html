이번 주 추가이전부터 동작

설문 결과는 결과 화면에 들어가는 순간 저장

  • 포트폴리오를 만들지 않아도 결과가 남음
  • 비로그인이면 저장만 건너뛰고 화면은 그대로 진행

이력은 저장 당시 값 그대로

  • 마이페이지 상세는 "저장 당시 기준" 스냅샷
  • 그날 이후 시세가 바뀌어도 내가 고른 구성은 유지

계정 기능 — 로그인 · 설문 저장 · 탈퇴

로그인 · 로그아웃 · 탈퇴

  • 로그인 구글 소셜 로그인만 사용, 세션 쿠키 발급. 실패하면 첫 화면에 안내
  • 상태 확인 앱 진입 시 GET /api/auth/me — 200이면 로그인, 401이면 비로그인(오류 아님)
  • 로그아웃 POST /api/auth/logout 후 화면 상태 초기화
  • 탈퇴 DELETE /api/auth/me — 저장한 포트폴리오 이력도 서버에서 함께 삭제

설문 결과 저장

  • 문항과 채점은 화면에서 끝내고, 결과(유형 · 운용방식)만 서버에 저장
  • PUT /api/users/me/investor-type
  • 초기화는 같은 주소에 빈 값을 보내는 방식
  • 마이페이지는 저장된 결과를 그대로 표시, 없으면 "아직 진단된 투자성향이 없어요"
  • 비로그인이면 로그인 버튼만, 로그아웃·탈퇴 버튼은 숨김

복리 계산기 — 모아가면 얼마가 될까

입력

시작 금액, 월 적립액, 투자 기간, 예상 연 배당률, 배당 지급 주기(월 · 분기 · 연), 배당 재투자 여부

계산 방식

매달 적립금을 더하고, 지급 주기마다 그 시점 자산에 (연 배당률 ÷ 연 지급 횟수)를 적용. 재투자를 고르면 배당금이 자산에 더해져 복리로 불어나고, 아니면 현금으로 받음

결과

최종 자산, 총 납입금, 누적 배당금(현금 수령 시), 주기별 자산 막대그래프와 표

안내

실제 수익률 · 배당률은 시장 상황에 따라 달라질 수 있는 참고용 계산

리밸런싱 계산기 — 비중이 틀어졌을 때

왜 필요한가

오래 모아가다 보면 가격 변동으로 처음 정한 비중이 달라짐 → 목표 비중으로 돌아가려면 무엇을 얼마나 사고팔아야 하는지 계산

입력 — 두 가지 방식

금액으로 종목별 보유 금액 입력, 총자산은 자동 합계
비중으로 총자산 하나 + 종목별 현재 비중(%)

결과

종목별 목표 금액, 현재 금액, 매수 · 매도 필요 금액. 현재 · 목표 비중 합계가 100%가 아니면 경고
